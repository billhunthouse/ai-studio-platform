## 文件说明

- `screens/`：原始 PNG，1440×900，按 `编号-页面名.png` 命名。
- `manifest.json`：机器可读清单，包含路由、分组、用途、状态、备注。
- `contact-sheet.png`：全部页面总览，适合快速浏览。
- `contact-sheet.svg`：可导入 Figma 的总览板，缩略图 + 页面名 + 路由。

## 捕获方法

1. 启动前后端，使用管理员账号登录。
2. 浏览器视口设为 1440×900。
3. 逐路由导航，等待页面加载后截图。
4. 不做任何视觉修改、不注入样式、不改变数据。

## 已知限制

- 截图是“当前数据状态”，部分页面为空表或空画布；空状态本身也是基线的一部分。
- 没有补拍弹窗、抽屉、错误、权限不足、加载骨架等状态；见 `../page-inventory.md` 的“待补拍状态”。
- 没有 1024 / 768 / 390 响应式截图；当前代码未定义这些断点。
- Baseline 是扁平截图，不是可编辑设计系统；Figma 优化稿请放在 `10 Redesign`。
