# 设计规范

## 色彩
| 用途 | Tailwind |
|---|---|
| 主色 / 选中 / 主按钮 | `blue-600`（hover `blue-500`），浅底 `blue-50` |
| 页面背景 | `slate-100` |
| 顶部导航 | `slate-900`，文字 `slate-300`，选中白色 + `border-blue-500` 下划线 |
| 卡片 | `bg-white border border-slate-200 rounded-lg shadow-sm` |
| 正文 / 次要 / 弱化 | `slate-800` / `slate-500` / `slate-500`（小字号不再用 `slate-400`，对比度不足） |
| 代码区 | `bg-slate-900 text-emerald-300 font-mono` |

## 状态语义色（`Tag` 组件）
| 语义 | 颜色 | 示例 |
|---|---|---|
| 成功 | emerald | 通过、成功、在线、已完成、正常、启用 |
| 失败 / 高优 | rose | 失败、P0、离线、异常、驳回、高危 |
| 进行中 / 待处理 | amber | 解析中、待评审、P1、警告 |
| 信息 | blue | P2、GET |
| 中性 | slate | 其他 |

## 字号与间距
- 正文、表格、表单：`text-xs`；卡片标题：`text-sm font-semibold`；页面标题：`text-base font-semibold`；指标数字：`text-2xl font-semibold`
- 控件高度统一 `h-8`；卡片头 `h-11`；卡片内边距 `p-4`；页面内边距 `p-6`；栅格间距 `gap-4`

## 布局骨架
- 顶栏 `h-12`：Logo + 全局菜单 + 项目空间/管理后台入口 + 项目切换器 + 通知 + 用户
- 侧栏 `w-52`：当前层级菜单，选中项 `border-l-2 border-blue-600 bg-blue-50 text-blue-700`
- 内容区：面包屑 → 标题 → 子 Tab（选中 `border-b-2 border-blue-600`）→ 内容
- 右下角固定任务悬浮窗 `w-72`

## 常用页面模式
- **列表页**：`Card` > `Toolbar`（搜索 + 状态筛选 + 右侧操作按钮）> `Table`（行尾操作列）
- **详情页**：左侧 1/4 信息卡 + 右侧 3/4 工作区
- **生成类页面**：左侧配置表单 + 右侧结果区；生成中显示分阶段进度条，并推送到任务悬浮窗
- **编排画布**：节点库 | 画布（点阵背景） | 节点配置，比例 1:3:1
- **空状态**：`h-60 grid place-items-center text-xs text-slate-400`

## 按钮
- `primary`：每个区域只放一个主操作
- `ghost`：次要操作（导出、编辑、详情）
- `danger`：删除、移除，置于操作列最后
