# 设计规范

> 2026-11 专业化改造后的前端设计基准。  
> 设计方向：**Precision Workspace**（冷静、精确、高信号密度）。  
> 完整目标系统见 `design/DESIGN.md`，Token 见 `design/tokens.proposed.json`。

## 1. 色彩

| 用途 | Token / Tailwind | 值 |
|---|---|---|
| 主色 / 主按钮 / 选中 | `brand-500` | `#2D5BFF` |
| 主色 hover / active | `brand-600` / `brand-700` | `#1F46E0` / `#1838B8` |
| 主色浅底 | `brand-50` | `#EEF3FF` |
| AI 能力强调 | `ai` | `#0891B2` |
| 页面背景 | `surface` | `#F5F7FB` |
| 顶栏 | `ink-950` | `#0B1220` |
| 卡片 | 白底 + `border-line` | `#FFFFFF` / `#E2E8F0` |
| 主文本 | `ink-900` | `#0F172A` |
| 次文本 | `ink-600` | `#475569` |
| 弱文本 | `ink-500` | `#64748B` |
| 成功 | `emerald-600` | `#059669` |
| 警告 | `amber-600` | `#D97706` |
| 危险 | `rose-600` | `#E11D48` |

规则：

- 一屏最多一个主色按钮；其余用 secondary / ghost / text。
- 状态色只表达状态，不做装饰；同一行最多两个彩色 Tag。
- 正文不使用 `slate-400` 作为可读文字。

## 2. 字号与排版

| 角色 | 字号 | 字重 |
|---|---|---|
| 页面标题 | 26–28px | 600 |
| 区块标题 | 15–20px | 600 |
| 正文 | 14px | 400 |
| 表格 | 13px | 400 |
| 标签 / 辅助 | 11–12px | 500 |
| 指标数字 | 28px | 600，tabular-nums |

字体：`Inter` / system + `PingFang SC`；代码使用 `JetBrains Mono` / `SFMono-Regular`。

## 3. 布局

- 顶栏 56px；侧栏 232px；内容区内边距 24px（宽屏 32px）；最大内容宽度 1600px。
- 页面骨架：面包屑 → 标题 + 一句说明 → 子 Tab → 内容。
- 卡片圆角 12px；卡片头 48px；卡片内边距 20px。
- 表格行高 48–52px；表头 40px；操作列固定在右侧。
- 详情页：320px 摘要栏 + 自适应工作区。
- 编排页：节点库 240px | 画布 | 配置 320px。
- 内容区底部预留 64px，避免任务浮层遮挡。

## 4. 组件

### Button

- `primary`：`brand-500` 实底、白字、h-9。
- `secondary`：白底、`border-line`、hover 主色。
- `ghost`：无边框、hover 浅底。
- `danger`：危险色文字、浅红 hover。
- `text`：纯文字按钮。
- 支持 `size="sm"`（h-8）和 `loading`。

### Input / Select / Textarea

- 高度 36px；圆角 8px；边框 `line`；focus 主色 + 4px 浅光环。
- 错误状态必须同时有边框、文案，不只靠颜色。
- 表单标签 12px/500，帮助文本 11px。

### Tag

- 5 种语义：success / warning / danger / info / neutral。
- 默认带 6px 状态圆点，浅底 + 同色边框。
- 优先级 P0 危险、P1 警告、P2 信息。

### Card / Table / Empty

- Card：白底、1px 边框、12px 圆角、极轻阴影。
- Table：13px、48px 行高、表头 `ink-50`、hover `brand-50/40`。
- 空状态：图标 + 解释 + 一个主操作；使用 `Empty` 或 `emptyAction`。
- 加载状态：表格骨架 6 行，不用整页 spinner。

### Modal / Drawer / Toast

- Modal 最大 640px，圆角 12px，标题栏 56px，遮罩带轻微模糊。
- Drawer 480/720px，右侧滑出，footer 固定。
- Toast 深色卡片，左下角，自动消失。

## 5. 页面模式

1. **工作台**：深色欢迎区 → 指标卡 → 趋势图 + 告警 → 项目/待办/动态。
2. **列表页**：页面头 → 指标摘要 → 搜索/筛选/操作 → 表格 → 分页。
3. **详情页**：左侧 320px 摘要 → 右侧 Tab 工作区 → 空状态引导。
4. **生成页**：左侧配置 → 右侧预览 → 底部生成/保存。
5. **编排页**：节点库 | 画布 | 配置面板。
6. **对话页**：会话列表 | 消息流 | 引用/工具调用。
7. **报告页**：摘要指标 → 失败分布 → 明细表 → 导出/重跑。

## 6. 状态要求

每个页面至少定义：

- 空状态：为什么空、下一步做什么。
- 加载状态：骨架屏。
- 错误状态：原因 + 重试。
- 权限不足：缺什么权限、找谁开通。
- 长内容：截断 + tooltip。
- 破坏性操作：二次确认 + 影响说明。

## 7. 可访问性

- 正文对比度 ≥ 4.5:1。
- 点击目标 ≥ 32px（桌面）/ 44px（移动）。
- 焦点环可见；图标按钮有 `aria-label`。
- 支持键盘：Tab、Enter、Esc。
- 动效 150–200ms，尊重 `prefers-reduced-motion`。

## 8. Token 治理

- 代码真相源：`src/index.css` 的 `@theme` + `src/components/ui/primitives.tsx`。
- 设计基线：`design/tokens.baseline.json`。
- 目标方案：`design/tokens.proposed.json`，经 Figma 批准后再落回代码。
- 禁止在页面里硬编码新的颜色/圆角/阴影；优先使用 `brand-*`、`ink-*`、`surface`、`line`、`shadow-card`。

## 9. 不做的事

- 不引入 Ant Design / MUI / shadcn 等第三方 UI 库。
- 不改变路由、接口、权限和业务动作。
- 不用 emoji 作为图标。
- 不用大面积渐变、玻璃拟态、霓虹光晕。
