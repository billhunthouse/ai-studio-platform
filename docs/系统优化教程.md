# 系统界面专业化改造教程

> 本文记录 2026-11-17 这轮改造的完整步骤，供后续继续优化时复用。  
> 改造原则：**先设计基础，再改页面；先改 3 个基准页，再扩散；不改路由、接口、权限和业务动作。**

## 1. 改造背景与目标

改造前的问题：

- 正文/表格 11–12px，长时间阅读疲劳。
- 所有页面都是“标题 + Tab + 白卡片 + 表格”，缺少页面类型差异。
- 顶栏入口过多，侧栏没有分组。
- 空状态、加载状态、错误状态基本缺失。
- 按钮、标签、卡片、表格的视觉层级弱。
- 只在 1280px 以上可用，没有响应式策略。

目标：把系统从“能用的内部后台”升级为 **Precision Workspace** 风格的企业级工作台：

- 深石墨顶栏 + 冷白画布 + 钴蓝主色 + 青色 AI 强调。
- 正文 14px、表格 13px、页面标题 26px、指标 28px。
- 卡片轻、边框细、阴影弱，靠留白和字重建立层级。
- 先做工作台、需求列表、需求详情 3 个基准页。

## 3. 第一步：建立设计 Token

### 3.1 修改 `src/index.css`

Tailwind v4 用 `@theme` 定义可生成工具类的变量：

```css
@import 'tailwindcss';

@theme {
  --font-sans: Inter, ui-sans-serif, -apple-system, "PingFang SC", sans-serif;

  --color-brand-50: #eef3ff;
  --color-brand-500: #2d5bff;
  --color-brand-600: #1f46e0;

  --color-ink-950: #0b1220;
  --color-ink-900: #0f172a;
  --color-ink-500: #64748b;

  --color-surface: #f5f7fb;
  --color-line: #e2e8f0;

  --radius-card: 12px;
  --shadow-card: 0 1px 2px rgba(15, 23, 42, 0.04);
}
```

这样就能在组件里使用：

```tsx
<div className="rounded-card border border-line bg-white shadow-card text-ink-900" />
```

## 4. 第二步：重做基础组件

文件：`src/components/ui/primitives.tsx`

### 4.1 Button

```tsx
<Btn>主操作</Btn>
<Btn v="secondary" size="sm">次要操作</Btn>
<Btn v="ghost" size="sm">工具栏操作</Btn>
<Btn v="danger" size="sm">删除</Btn>
<Btn loading={busy}>保存</Btn>
```

新增能力：

- `v`: primary / secondary / ghost / danger / text
- `size`: md（36px）/ sm（32px）
- `loading`: 自动禁用 + spinner
- `focus-visible` 焦点环

### 4.2 Input / Select / Textarea / Field

- 高度 36px，圆角 8px，边框 `line`。
- focus：主色边框 + 4px 浅光环。
- `Field` 的 label 12px/500，hint 11px。

### 4.3 Card / Stat / Tag / Empty / Skeleton

- `Card`：12px 圆角、1px 边框、20px 内边距、48px 标题栏。
- `Stat`：28px 数字、delta 胶囊、可选 hint/icon。
- `Tag`：5 种语义色 + 默认状态圆点。
- `Empty`：图标 + 说明 + 可选操作。
- `Skeleton`：加载骨架。

### 4.4 Table

文件：`src/components/ui/Table.tsx`

新增：

- `loading`：渲染 6 行骨架。
- `emptyAction`：空状态下的主操作。
- 行高 48–52px，表头 `ink-50`，hover `brand-50/40`。
- 操作列固定在右侧，按钮间距统一。

用法：

```tsx
<Table
  cols={["编号", "名称", "状态"]}
  rows={rows}
  loading={loading}
  empty="还没有数据"
  emptyAction={<Btn size="sm">+ 新建</Btn>}
  actions={(i) => <Btn v="secondary" size="sm">详情</Btn>}
/>
```

### 4.5 Modal / Drawer / Toast

文件：`src/components/ui/Overlay.tsx`

- Modal：12px 圆角、56px 标题栏、遮罩模糊、footer 浅底。
- Drawer：480/720px，header/footer 固定。
- Toast：深色卡片、左下角。
- 保留原有的焦点陷阱、Esc 关闭、焦点恢复。

### 4.6 Icon

新增 `src/components/ui/Icon.tsx`：


图标为 1.7px 线性 SVG，不引入第三方图标库。菜单、空状态、任务浮层先用它。

6. **状态**：空/加载/错误/权限。
7. **响应式**：至少保证 1280 不横向溢出。

## 11. 常见问题

**Q：自定义颜色类不生效？**  
A：确认写在 `@theme` 里，并重启 Vite；Tailwind v4 只扫描源码中出现的类名。

**Q：传入 `className="h-8"` 没覆盖组件高度？**  
A：Tailwind 工具类排序不是按字符串顺序。优先用 `size="sm"`，不要用 className 硬覆盖。

**Q：表格太宽？**  
A：`Table` 外层有 `overflow-x-auto`；如果页面本身横向溢出，检查是否有固定宽度子元素。

**Q：Tag 变宽了？**  
A：新版默认带状态圆点；不需要圆点时传 `dot={false}`。

**Q：Card 内容变矮/变高？**  
A：Card 内边距从 16px 改为 20px；密集表格页可以用 `className="[&>div]:p-4"` 局部覆盖。

**Q：截图失败？**  
A：Mac 锁屏时 IAB 截图会超时；先解锁屏幕，或使用 DOM/布局检查。
