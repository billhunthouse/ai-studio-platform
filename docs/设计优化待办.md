## 5. 已知问题 / 风险

| 问题 | 影响 | 建议 |
|---|---|---|
| 少量深色代码块仍使用 `slate-900` / `slate-800` | 属于编辑器/代码区视觉，不影响主界面 | 保留；如统一暗色主题再抽 Token |
| `Table` 使用 index 作为 key | 排序/删除/选择可能错位 | 改成业务 ID，或在 Table 内部生成稳定 key |
| `Tag` 用正则可推断语义 | `P1`/`待评审` 等可能误判 | 页面显式传 `c`，不要依赖自动推断 |
| `Btn` 的 `className` 可能和 size 冲突 | 高度不稳定 | 统一用 `size`，不要传 `h-8` |
| `Card` 内边距 20px | 密集页面变高 | 用 `className="[&>div]:p-4"` 局部覆盖 |
| 详情页生成进度是前端定时器模拟 | 进度与真实任务不一致 | 接入任务 SSE / 轮询真实进度 |
| Dashboard 数据来自 seed/汇总 | 指标不是实时 | 接入真实统计接口并标注更新时间 |
| API 管理当前为空数据 | 空状态无法验证有数据布局 | 导入 OpenAPI 或 seed 几条接口 |
| 需求列表有 4 个重复技术方案文档 | 模块数量被抬高 | 业务确认后删除/合并重复上传 |
| Figma 远程 MCP OAuth 403 | 无法在 ZCode 内 Code to canvas | 用 Claude Code/Cursor 或截图基线 |
| Mac 锁屏时截图超时 | 无法补拍视觉回归 | 解锁后补拍 3 个基准页 |
