# 前端模块清单

## 全局层
| 模块 | 页面 | 职责 |
|---|---|---|
| 认证 | 登录、接受邀请 | JWT 登录、OAuth 入口、邀请激活、退出 |
| 工作台 | 概览 | 我的项目、待办、近期动态、Token/算力趋势、告警、快捷创建 |
| 技能市场 | 技能列表、MCP 工具 | 按标签筛选；导入 `SKILL.md`；编辑名称/描述/参数/提示词；一键添加到工作流 |
| MCP 服务 | 服务列表 | 登记命令/参数/环境变量、连接测试、工具列表（管理员） |
| 团队管理 | 成员列表、角色权限、项目分配 | 邀请制开号、四种角色、项目级授权 |
| 个人中心 | 个人信息、安全设置、我的资产、API Key | 资料与密码、产物、API Key 管理 |

通用组件：全局导航栏（项目切换与编辑）、通知中心、任务状态悬浮窗。

## 项目层
| 模块 | 页面 | 职责 |
|---|---|---|
| 项目概览 | 概览 | 需求数、用例数、生成任务、通过率、成员、最近活动 |
| 需求管理 | 需求列表、需求详情 | 多文件上传与真实解析；AI 拆分主/子需求；多页原型；表单/JSON 编辑；版本对比 |
| 测试用例 | 用例列表、AI 生成用例、用例评审 | CRUD；LLM 生成；评审内编辑、通过并保存；`.xlsx` 导出/导入 |
| API 测试 | 接口管理、调试面板、套件与定时任务、执行报告 | OpenAPI 导入；调试；批量执行；报告 |
| WebUI 自动化 | 元素库、用例脚本、录制回放、执行记录 | POM、脚本编辑、多浏览器执行记录 |
| App 自动化 | 设备管理、UI Flow 编排、执行记录 | 设备池、图像识别流程、执行记录 |
| AI 助手 | 对话助手、工作流编排器 | 对话问答；节点编排；预置需求→原型/接口模板 |
| 知识库 | 知识库列表、文档管理、召回测试 | 真实解析、切片入库、关键词召回；AI 对话引用 |
| 任务与报告 | 任务列表、Agent 评测、版本对比 | 任务查看、重试、Agent 评测报告/真实链路验证/trace、版本 diff |

## 管理员层（`/admin`）
| 模块 | 页面 | 职责 |
|---|---|---|
| 全局模型配置 | 模型供应商、模型路由规则、连接测试 | 多供应商、BYOK、任务路由 |
| 系统管理 | 用户管理、环境检测、通知配置 | 用户启停/邀请、依赖健康检查、通知渠道 |
| 平台审计 | 审计日志 | 生成、模型消耗、导出与敏感操作追溯 |

## 当前实现状态

- 前端 42 条业务路由：认证、全局 5 模块、项目 9 模块、管理员 3 模块。
- 后端 FastAPI + PostgreSQL + Alembic；JWT/Refresh Cookie；邀请制；四种角色；项目数据隔离。
- 已实现真实文件解析（PDF/DOCX/Markdown/TXT）、AI 需求拆分与用例生成、Excel 双向、SKILL.md 导入、MCP 连接测试。
- 知识库真实入库/召回、AI 对话知识库增强、API 调试真实请求、变更审计、需求文档预览。
- 「物业小程序」已作为真实项目导入：8 主 + 65 子需求、36 条用例、12 篇文档 / 184 切片。
- 数据工厂模块已彻底删除（菜单、路由、页面、接口、种子、文档）。
- 任务进度仍由前端模拟；真实执行器、邮件服务、对象存储未接入。
